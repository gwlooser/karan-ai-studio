# KARAN AI STUDIO v0.3

Private, local-first starter for planning education videos up to 60 minutes.

## What works now
- Chapter splitting from `Chapter N:` headings
- Script timing review at an estimated 130 words/minute
- A lightweight storyboard and editable-in-browser SVG concept diagram
- A consent gate before a simulated voice-track preparation action
- Responsive layout for phone, desktop and tablet

## Deliberate placeholders
- No voice cloning or synthesis provider is connected
- No cinematic/video rendering provider or API keys are included
- Android APK (Capacitor) and Windows app (Tauri) are future packaging steps
- No deployment is configured

## Run and test
`npm test` then `npm start` and open `http://localhost:4173`.

This project does not collect or transmit scripts, voices, or keys.
